# 📊 Product Sales Dashboard 2026

![Dashboard](https://github.com/hamidraza6/Product-Sales-Dashboard-2026/blob/main/Screenshot%202026-03-08%20001049.png)

## 📌 Project Overview

The **Product Sales Dashboard 2026** is a data visualization project built to analyze sales performance, profit distribution, and product category performance across different cities and states in Pakistan.

This dashboard helps businesses quickly understand key insights such as:

* Which cities generate the most profit
* State-wise contribution to total profit
* Top performing product categories
* Overall sales performance indicators

---

## 🚀 Key Insights

### 🏙️ Profit by City

The dashboard shows profit distribution across major cities:

| City      | Profit  |
| --------- | ------- |
| Islamabad | Highest |
| Hyderabad | High    |
| Peshawar  | Medium  |
| Karachi   | Medium  |
| Nawabshah | Low     |
| Lahore    | Lowest  |

---

### 🗺️ Profit by State

A donut chart visualizes the contribution of each state:

| State  | Contribution |
| ------ | ------------ |
| Sindh  | 46%          |
| Punjab | 33%          |
| KPK    | 20%          |

Sindh contributes the **largest share of total profit**.

---

### 📦 Profit by Product Sub-Category

Top performing categories include:

* 💻 Laptop
* 🛋️ Sofa
* 📱 Phone

Lower performing categories:

* 📄 Paper
* ✏️ Pen
