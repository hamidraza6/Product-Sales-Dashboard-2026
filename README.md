
# 📊 Product Sales Dashboard 2026

## 📌 Project Overview

The **Product Sales Dashboard 2026** is a data visualization project developed to analyze **sales performance, profit distribution, customer contribution, and product category performance** across different cities and regions.

This dashboard provides a clear overview of business performance and helps identify key insights such as:

* Which cities generate the most profit
* Regional contribution to total profit
* Top-performing product sub-categories
* Customer profit contribution
* Monthly sales trends
* Overall sales performance indicators

The dashboard was created using **Power BI** to demonstrate **data analysis and business intelligence skills**.
